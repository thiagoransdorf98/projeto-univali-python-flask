CASO DE USO IDEAL

Quando faz sentido usar Flask?

Quando o projeto precisa de controle sobre sua estrutura e de um ponto de partida simples — por exemplo, uma API para um aplicativo ou um painel web acadêmico.

Diferencial: o Flask oferece uma base enxuta. Recursos como banco de dados, autenticação e validação podem ser adicionados conforme a necessidade.

03 / O CÓDIGO DO SERVIDOR

O que acontece
por trás da página?

Este é o código do servidor que entrega a página de documentação. O HTML e o CSS ficam em arquivos separados para facilitar a organização.

Pyapp.pyServidor Flask
CÓDIGO-FONTE 
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def inicio():
    return render_template("index.html")

if __name__ == "__main__":
    app.run(debug=True)
01

Importação

Flask cria a aplicação; render_template carrega o HTML da pasta templates.

02

Rota principal

@app.route("/") associa o endereço principal à função inicio().

03

Resposta

render_template("index.html") gera a página HTML enviada ao navegador.

04

Inicialização

python app.py inicia o servidor local para testar a aplicação.

Navegador→ requisição GET / →Flask→ resposta HTML →Página exibida

Atenção: debug=True é para desenvolvimento local. Não deve ser usado como configuração de um servidor de produção.

04 / CONCLUSÃO

O uso do Python com Flask permite observar, na prática, como uma aplicação recebe uma requisição HTTP e devolve uma resposta. A estrutura simples ajuda a estudar rotas, organização de arquivos e integração entre Back-End e Front-End.
